# TD_Frontend_reactjs

Standalone React (Vite) frontend — not connected to any backend or
Angular app by default. Separate from the TD_*_BE_nodejs_FE_reactjs_FE_angularjs
connected project-type repos, which combine backend+React+Angular together.

Each branch is `<project-type>_reactjs<version>` and carries that
project type's own real React logic, extracted standalone — e.g. the
Micro-Frontend shell's iframe embed, the SaaS Platform's customer-only
API calls, etc.

See ARCHITECTURE.txt on each branch for build commands and details.

Branches: 5 project types × React versions (18, 20, 22, 24).
