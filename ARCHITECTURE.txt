PROJECT TYPE: Frontend Web Application / SPA (JavaScript taxonomy)
BUILD TOOL: Webpack

BUILD COMMANDS
==============
npm install
npm run build    # real webpack production bundle -> dist/
npm run dev      # webpack-dev-server
npm test         # mocha + chai

ARCHITECTURE
============
A minimal single-page React application, bundled with Webpack (webpack.config.js +
babel-loader for JSX, html-webpack-plugin for the HTML shell, style-loader/css-loader
for CSS). Chosen because Webpack is the most widely used bundler for general-purpose
SPA builds, distinct from the Vite-based builds used elsewhere in this repo's other
branches.

  src/main.jsx      React entry point
  src/App.jsx        root component
  src/widgets.js      pure-logic module (tested)
  test/widgets.test.js  mocha + chai test suite
