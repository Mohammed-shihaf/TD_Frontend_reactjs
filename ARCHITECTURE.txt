PROJECT TYPE: Node.js Application (JavaScript taxonomy)
BUILD TOOL: esbuild

BUILD COMMANDS
==============
npm install
npm run build    # esbuild bundles src/cli.js -> dist/cli.bundle.js (real Node CLI bundle)
npm start        # runs the built bundle
npm test         # mocha + chai

ARCHITECTURE
============
A minimal Node.js command-line application, bundled with esbuild (platform: "node",
single-file ESM output with a shebang banner). esbuild is chosen for its speed and
because it's a real, widely-used tool for bundling Node.js CLIs/services into a single
distributable file, distinct from the browser-focused bundlers used in this repo's
other taxonomy branches.

  src/widgets.js   pure-logic module (shared, tested)
  src/cli.js        Node CLI entry point
  test/cli.test.js  mocha + chai test suite
