PROJECT TYPE: Static Web Application (JavaScript taxonomy)
BUILD TOOL: Vite (multi-page mode)

BUILD COMMANDS
==============
npm install
npm run build    # vite build -> dist/ with 2 real HTML entry points (index.html, pages/about.html)
npm test         # mocha + chai

ARCHITECTURE
============
A real static multi-page site - no client-side framework/router, no React - built with
Vite's multi-page build.rollupOptions.input configuration (multiple real HTML entry
points, each with its own bundled JS). This is Vite's genuine "static site" use case,
distinct from the SPA build (single entry, client-side routing) used in this repo's
other Vite-based branches.

  index.html         home page
  pages/about.html   second real page
  src/home.js         plain JS, no framework
  src/widgets.js      pure-logic module (shared, tested)
