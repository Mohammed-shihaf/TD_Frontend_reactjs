PROJECT TYPE: Browser Extension (JavaScript taxonomy)
BUILD TOOL: Parcel

BUILD COMMANDS
==============
npm install
npm run build    # parcel build manifest.json -> dist/ (real Manifest V3 extension bundle)
npm test         # mocha + chai

ARCHITECTURE
============
A minimal, real Manifest V3 browser extension - a popup UI built with React, bundled
by Parcel using its zero-config @parcel/config-webextension preset, which understands
manifest.json as the build entry point and correctly bundles/copies the referenced
popup HTML/JS. Parcel is chosen for this because of that first-class, zero-config
web-extension build target, distinct from the other bundlers used in this repo's
other taxonomy branches.

  manifest.json     MV3 extension manifest (entry point for the build)
  src/popup.html    popup UI shell
  src/popup.jsx     React popup component
  src/widgets.js    pure-logic module (shared, tested)
