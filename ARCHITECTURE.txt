PROJECT TYPE: JavaScript Library / NPM Package (JavaScript taxonomy)
BUILD TOOL: Rollup

BUILD COMMANDS
==============
npm install
npm run build    # rollup -c -> dist/index.cjs.js + dist/index.esm.js (real dual-format build)
npm test         # builds, then mocha + chai (source AND the built CJS artifact via require())

ARCHITECTURE
============
A minimal, real npm-publishable utility library, built with Rollup to produce both a
CommonJS and an ES Module output (package.json "main"/"module"/"exports" wired to the
real build artifacts). Rollup is chosen because it's the standard tool for bundling
libraries (as opposed to applications) - its tree-shaking and dual-format output are
exactly this use case, distinct from the app-bundler tools used elsewhere in this repo.

  src/index.js        library source (also the package's public API)
  test/index.test.js  tests against the source
  test/dist.test.js   tests against the actual built dist/index.cjs.js artifact
