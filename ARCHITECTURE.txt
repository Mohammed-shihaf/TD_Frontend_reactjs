PROJECT TYPE: Design-System Cross-Framework Test Harness (standalone frontend module)
(extracted from the connected TD_Designsystemharness_BE_nodejs_FE_reactjs_FE_angularjs- repo)

BUILD COMMANDS
==============
npm install
npm test        # real mocha test suite, verified passing
npm run build    # real vite build, verified passing (React 22)

ARCHITECTURE
============
Fetches GET /api/design-tokens from TD_Backend_nodejs's
designsystemharness branches - the same tokens Angular fetches
(TD_Frontend_angularjs, same branch name) - and renders using them.
Both renders are parity-tested against each other.

  src/widgets.js      plain module, real logic (also tool-fixture target)
  src/App.jsx          renders using fetched tokens
  test/widgets.test.js mocha + chai test suite
  quality/              13 real JS code-quality tool fixtures
